## 人工步骤

### 供应商

1. 添加渠道，先选 API 渠道类型，再填写名称、API 地址和真实 Key。
2. 获取模型，确认返回所有类型、去重、图片／视频／文本／ASR／TTS 分类及多模态元数据；保存并重启，模型目录应保留。
3. 修改显示名称，Key 留空，原有凭据应保持不变。
4. 修改基础地址，Key 留空，应用应要求重新输入密钥。
5. 错误 Key 应提示认证失败，不能显示 API Key 或原始错误响应。
6. 服务不支持 /models 时手动添加语音模型；不得显示“连接验证成功”。
7. 手动修改未知模型能力；ASR／LLM 选择器只出现当前渠道能够尝试相应接口的模型；这些任务选择器不得裁剪完整模型目录。
8. 删除当前供应商，对应 Key 和模型选择应一并清除。

### 账号登录渠道

1. 先选 Codex／Antigravity／Grok；不应出现 API 地址、API Key，名称可直接使用默认值。
2. 点击登录，在系统浏览器完成服务商授权后回到 AIHub；不要求粘贴到 API Key。
3. 自动获取模型后保存；选择对话模型整理文字。成功调用才出现「调用已验证」。
4. 取消、拒绝、超时、端口占用时给出明确结果；不覆盖旧凭据、不保存不完整输出。
5. 重启后令牌过期能刷新；更换渠道类型不能发送旧令牌到新的服务。
6. Antigravity 首先确认风险；获取目录不要求生成项目、不上传音频或生成内容。文字生成时未分配项目才提示官方启用，不借用其他项目或自动开户。
7. Grok／Codex 额度或权限不足时正常报错，不自动改走按量计费 API。
8. Antigravity 同一基础模型的高／低档只占一行；在模型面板、编辑弹窗或 LLM 选择处更改「思考」，保存／重启后保持该档，调用对应真实 ID。实际档位效果仍需真实账户验收；不得把低档调用成功当成高档或中档也已验证。当前账号目录只有低／高就只显示这两档，不根据 Gemini 官方 API 的中档能力进行推测。

### 模型规格与价格

1. 选择模型后打开「模型详情」，核对任务、模态、协议、思考规格及来源；图片输入不能显示为已接入图片生成。
2. 点击「更新规格与价格」，确认只访问 models.dev，不发送密钥、输入或生成请求；取消 / 网络失败不丢原文和配置。
3. 官方 API 精确 ID 可补参考字段；Antigravity / Codex / Grok 及未知中转保持自身渠道信息，不借用公开 API 档位和单价。
4. 同一 OpenAI 风格渠道两个模型分别选 Chat / Responses，实际请求走各自接口；失败不换协议。恢复默认应恢复服务声明，密钥不变。
5. 价格有单位、时间、来源，旧快照保留；未知不等于免费，过期标参考，订阅显示账户额度。
6. 更新应用时存在输入 / 编辑应保留当前窗口，不强制重启。
7. 官方 API 模型详情按实际规格选择思考参数；服务默认不等于关闭，Gemini 等级 / 预算不同时发送，Anthropic 开启预算至少 1024 且小于输出上限。未知中转 / 订阅不套用公共参数；声明撤回后失败，不自动降档。
8. 「用量」默认不存记录；主动开启后成功文字调用只保存计数与价格版本，原文 / 输出不写入配置。失败 / 取消费用明确未计入，保存失败仍保留文字，清除记录不改变凭据 / 原文 / 模型。

### 语音识别

小米 ASR 另验证自动 WAV 转换、自动／中文／英文语言、7 MiB 限制以及识别质量。

1. 首次录音应弹出系统麦克风权限提示；拒绝后应给出系统设置指引，导入仍可使用。
2. 录制 10–30 秒中文，含人名、数字和中英文术语。输入电平及计时应随录音变化。
3. 停止录音不应自动上传；点击「仅识别」或「识别并润色」后才应出现网络处理状态。
4. 检查 OpenAI／Groq／硅基流动各自实际支持的模型和识别质量。
5. 导入 m4a／wav／mp3，确认原文件名不会传给供应商，导入原文件不会删除。
6. 超过 24 MiB 或空文件应在上传前被拒绝。
7. 转写失败／取消应保留已有文字和音频，允许重试；旧请求不得覆盖新结果。
8. 成功后对应语音模型应显示“调用已验证”，其他模型仍未验证。
9. 录音达到 10 分钟时应停止并保留，不自动上传。
10. 正常退出应用后本次录音临时文件应删除。

### ASR → LLM

1. 选择 ASR 模型和 LLM 模型，导入音频，点击「识别并润色」。状态应先显示 ASR，成功后显示 LLM；识别原文和润色结果分开。
2. LLM 失败／取消时已识别的原文、音频应保留；可以只点击文字处理重试，不重新上传音频。
3. 选择「仅识别」只调用 ASR；未选择 LLM 时不能执行「识别并润色」。
4. 不录音，直接输入／粘贴文字，文本模型仍能独立整理或转换为提示词。
5. 图像／视频条目应出现在目录，但不应冒称图片或视频生成任务已经适配。

### 提示词与隐私

1. 选择不同供应商的对话模型，整理文字或转为提示词；原始听写文字不应被覆盖。
2. 转换失败／取消不得清空原文字。
3. 检查设置文件不包含 Key、音频或识别文字。
4. 复制按钮应写入剪贴板，不向其他应用自动粘贴。
5. 远程 HTTP URL 应被拒绝；本机回环 HTTP 可用于兼容服务。
6. API 重定向应被拒绝，不应把 Authorization 转发给目标地址。
